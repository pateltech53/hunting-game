# Bundled typefaces

Both are used under the SIL Open Font License 1.1, which permits bundling
and redistribution inside a work like this one.

- **Playfair Display** — Claus Eggers Sørensen. Display face: the title,
  headings, location names and species names.
  https://fonts.google.com/specimen/Playfair+Display

- **Inter** — Rasmus Andersson. Text face: everything else — body copy, the
  HUD, settings, numbers.
  https://fonts.google.com/specimen/Inter
